# LCC Projects – Assembler & Linker

This repo contains C projects for the LCC course: an Assembler (a1.c) and a Linker (l.c).
Perfect for learning how your code goes from human-readable C/assembly to machine instructions!

## Files

### a1.c – Assembler

Converts assembly code into machine code

Handles labels, instructions, and memory addresses

### l.c – Linker

Combines object files into a single executable

Resolves symbols and addresses between files

## 💻 How to Compile & Run

### Compile each program with GCC:

`gcc a1.c -o assembler`

`gcc l.c -o linker`


### Run the programs:

`./assembler file.a`

`./linker file1.o file2.o file3.o`


(Replace file names with your actual test files)
